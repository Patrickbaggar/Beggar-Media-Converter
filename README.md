# Beggar-Media-Converter
Convert Video/ Audio/ Photo file format, offline, locally, on a PC, free of charge

Beggar Media Converter 2.2.0
Windows 10 22H2 / Windows 11 x64

1. Extract the whole ZIP to a regular local folder.
2. Open Beggar Media Converter.exe.
3. Open README.md for the full English guide and its links to all 30 languages.
   If needed, open the Markdown files in Notepad.

Language help is in Docs\Guides. Traditional Chinese is README-zh-Hant.md.
Use the Language tab to save a preference. It takes effect after reopening.

Use Video, Audio or Photo to convert local media. Docs\Training.md has
hands-on exercises. Docs\Engineering.md records the design and checks.

Diagnostics lets you preview and save a local log. GitHub\PUBLISH.md explains
how to set the GitHub issue destination and publish the ZIP as a Release asset.
